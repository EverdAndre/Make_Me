# Make Me

Aplicação desenvolvida como parte de um curso de introdução ao ASP.NET.

O projeto é uma aplicação simples de gerenciamento de tarefas, criada para praticar os fundamentos do ASP.NET MVC, Razor Views, Controllers, Models e persistência de dados com Entity Framework.

## Funcionalidades

- Listar tarefas cadastradas
- Criar novas tarefas
- Editar tarefas existentes
- Concluir tarefas, salvando a data e hora de conclusão
- Excluir tarefas

## Tecnologias utilizadas

- ASP.NET MVC
- Razor Views
- Entity Framework Core
- SQLite
- Bootstrap

## Objetivo do projeto

Este projeto tem fins educacionais e foi criado para acompanhar os estudos iniciais em desenvolvimento web com ASP.NET. A aplicação demonstra o fluxo básico de uma aplicação MVC, incluindo rotas, formulários, ações de controller e operações de banco de dados.

## Como executar

No terminal, dentro da pasta do projeto, execute:

```bash
dotnet run
```

Depois, acesse a URL exibida no terminal, geralmente:

```text
http://localhost:5000
```

ou

```text
https://localhost:5001
```

## Observação

Como este projeto faz parte de um curso introdutório, o foco principal está no aprendizado dos conceitos básicos e na evolução gradual da aplicação.
